## 키 표기법

Emacs 문서의 키 표기는 이렇게 읽는다.

| 표기 | 의미 | macOS에서 |
|---|---|---|
| `C-x` | Ctrl 누른 채 x | `Ctrl + x` |
| `M-x` | Meta 누른 채 x | `Option + x` (또는 `ESC` 후 x) |
| `C-c l a` | Ctrl+c, l, a를 순서대로 | 이어 누르기 (동시 아님) |
| `C-u` | 다음 명령에 옵션(prefix argument)을 붙임 | 예: `C-u C-c g b` |

`C-c l a`처럼 여러 타로 이뤄진 키는 **동시에 누르는 게 아니라 순서대로** 누른다. 중간에 멈추면 which-key가 다음 후보를 보여 준다.

## 잘못 눌렀을 때 — 가장 중요한 키

- `C-g`: 진행 중인 입력/명령 취소. IntelliJ의 `ESC`에 해당. **뭔가 꼬이면 일단 `C-g`를 연타한다.**
- `C-x u`: 실행 취소(undo)
- `M-x`: 모든 명령을 이름으로 실행. 키를 몰라도 `M-x`에서 명령 이름을 검색하면 된다.

## 버퍼(buffer)와 창(window)

IntelliJ의 "에디터 탭" 대신 Emacs는 **버퍼**(열린 파일)와 **창**(화면 분할 영역)으로 움직인다.

| 키 | 동작 |
|---|---|
| `C-x b` | 버퍼 전환 (consult — 미리보기 지원) |
| `C-x C-b` | 버퍼 목록 (ibuffer) |
| `C-x k` | 현재 버퍼 닫기 |
| `C-x 2` / `C-x 3` | 창을 위아래 / 좌우로 분할 |
| `C-x o` | 다른 창으로 커서 이동 |
| `C-x 1` | 현재 창만 남기고 전부 닫기 |
| `C-x 0` | 현재 창 닫기 |

테스트 출력이나 diff가 새 창으로 떴을 때: `C-x o`로 넘어가서 보고, 다 봤으면 `C-x 1`로 원래 화면으로 돌아오는 패턴을 몸에 붙이면 편하다.

## 파일 열기와 저장

| 키 | 동작 |
|---|---|
| `C-x C-f` | 경로로 파일 열기 |
| `C-c p f` | **프로젝트 안** 파일 이름으로 찾기 (IntelliJ `Cmd+Shift+O`) |
| `C-x C-s` | 저장 |
| `C-c t t` | treemacs 파일 트리 토글 |

## 편집 자주 쓰는 것

| 키 | 동작 |
|---|---|
| `C-s` | 현재 버퍼 검색 (consult-line) |
| `C-S-d` 또는 `M-S-↓` | 현재 줄 아래로 복제 |
| `M-S-↑` | 현재 줄 위로 복제 |
| `C-w` / `M-w` / `C-y` | 잘라내기 / 복사 / 붙여넣기 |
| `C-SPC` | 선택(마크) 시작 |
