한 번에 다 익히려 하지 말고, 주차별로 **그 주의 키만** 반복한다. 나머지는 which-key와 `M-x`로 버틴다.

## 1주차: 생존 키와 검색

**목표**: 마우스 없이 파일을 찾고 읽을 수 있다.

- `C-x C-f`, `C-x b`, `C-x k`, `C-x 1/2/3/0`, `C-g`
- `C-s`(버퍼 검색), `M-s r`(프로젝트 검색), `C-c p f`(파일 찾기)

**과제**: 회사 프로젝트를 `C-c p p`로 열고, 특정 로그 메시지 문자열을 `M-s r`로 찾아 해당 파일을 연다. 창을 좌우로 나눠(`C-x 3`) 두 파일을 비교한다.

## 2주차: 코드 읽기

**목표**: call path를 IntelliJ만큼 빠르게 추적한다.

- `M-g s`, `M-.`, `M-,`, `M-?`, `C-c l g i`
- `M-g n`/`M-g p`로 진단 훑기

**과제**: 컨트롤러 엔드포인트 하나를 골라 서비스 → 리포지토리까지 `M-.`로 내려갔다가 `M-,`로 되돌아온다. 인터페이스에서 `C-c l g i`로 구현체를 찾는다.

## 3주차: 테스트와 수정

**목표**: 수정 → 테스트 루프를 Emacs 안에서 돈다.

- `C-c l a`(code action), `C-c l r`(rename), `C-c l f`(format)
- `C-c g t`, `C-c g c`, `C-c g r`

**과제**: 테스트를 하나 일부러 깨뜨리고 `C-c g t`로 실행 → `M-g n`으로 실패 지점 점프 → 고치고 `C-c g r`로 재실행.

## 4주차: Git, 디버깅, PR

**목표**: 커밋과 디버깅까지 Emacs로 마감한다.

- magit: `C-x g`, `TAB`, `s`, `c c`, `P p`
- dape: `C-c d b` → `C-c g d` → 스테핑

**과제**: breakpoint를 찍고 `C-c g d`로 테스트를 디버그해 변수 값을 확인한다(`C-c d l`). hunk 단위 stage로 커밋을 두 개로 쪼개 본다.

## 이후: AI agent 운영 허브

Emacs는 코드 리뷰와 작은 수정의 메인 화면으로 두고, 긴 작업은 Codex/Claude/tmux 세션에서 돌린다. 결과 확인은 `magit`(diff), `M-s r`(검색), eglot(추적), `C-c c`(org 메모)로 처리한다.
