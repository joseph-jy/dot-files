**상황**: "주문 API가 500을 뱉는다"는 리포트를 받았다. `OrderService` 근처를 추적해야 한다.

## 1. 프로젝트 열기

1. `C-c p p` — 프로젝트 목록에서 해당 프로젝트 선택
2. 이어서 파일 찾기 프롬프트가 뜨면 아무 Java/Kotlin 파일이나 하나 연다
3. 모드라인에 `eglot`이 표시되고 jdtls 인덱싱이 끝날 때까지 잠깐 기다린다

:::note
`C-c t t`로 treemacs 사이드바를 열어 두면 디렉토리 구조를 눈으로 보면서 움직일 수 있다. 단, 파일을 찾을 때는 트리 클릭보다 아래의 검색 키들이 훨씬 빠르다.
:::

## 2. 클래스/심볼 찾아가기

IntelliJ 대응 관계로 외우면 빠르다.

| 하려는 것 | IntelliJ | Emacs |
|---|---|---|
| 클래스/심볼 이름으로 점프 | `Cmd+O` | `M-g s` |
| 파일 이름으로 점프 | `Cmd+Shift+O` | `C-c p f` |
| 전체 텍스트 검색 | `Cmd+Shift+F` | `M-s r` (ripgrep) |
| 현재 파일 안 검색 | `Cmd+F` | `C-s` |

1. `M-g s` 입력 후 `OrderService` 타이핑 — 워크스페이스 심볼 목록이 뜬다
2. 목록에서 위아래로 움직이면 **미리보기**가 같이 움직인다
3. `RET`(엔터)로 확정 이동

검색어는 부분 일치라 `ordserv`처럼 대충 쳐도 orderless가 걸러 준다.

## 3. 정의/사용처 오가기

| 키 | 동작 | IntelliJ |
|---|---|---|
| `M-.` | 정의로 이동 | `Cmd+B` |
| `M-,` | 직전 위치로 복귀 | `Cmd+[` |
| `M-?` | 사용처 전부 찾기 (Find Usages) | `Opt+F7` |
| `C-c l g i` | 인터페이스 → 구현체로 이동 | `Cmd+Opt+B` |
| `C-c l g t` | 타입 정의로 이동 | |

전형적인 추적 흐름:

1. 컨트롤러에서 서비스 호출부에 커서를 두고 `M-.` — 서비스 구현으로 들어감
2. 다시 `M-.`를 반복하며 call path를 따라 내려감
3. `M-,`를 누를 때마다 한 단계씩 되돌아옴 (스택처럼 동작)
4. "이 메서드를 누가 부르지?"가 궁금하면 `M-?` — 사용처 목록이 미리보기와 함께 뜸

인터페이스(`OrderRepository` 등)에서 `M-.`는 인터페이스 선언으로 가버린다. **구현체**가 보고 싶으면 `C-c l g i`.

## 4. 에러/경고 훑어보기

- `M-g n` / `M-g p`: 다음/이전 진단으로 점프
- `C-c l d`: 현재 버퍼의 진단 목록 창
- `M-g f`: 진단 목록을 미니버퍼에서 검색(consult-flymake)
